1. Performance: The "Perfect 100" Fixes
Even a fast site can be slowed down by small technical oversights.

Explicit Image Dimensions: Ensure every <img> tag in your Astro or HTML code has a width and height attribute. This prevents Cumulative Layout Shift (CLS), which is a major ranking factor for Google.

Preload Your Hero Image: Add <link rel="preload" as="image" href="..."> in your <head> for the main banner. This makes the Largest Contentful Paint (LCP) nearly instant.

WebP Everything: If any images are .png or .jpg, ask the Replit Agent to convert them to WebP. It reduces file size by up to 30% without losing quality.
